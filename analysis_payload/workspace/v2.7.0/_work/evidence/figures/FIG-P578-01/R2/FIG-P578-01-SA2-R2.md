## 3. 完整输入验证与每轮原子顺序

图的主链按下列严格顺序组织：

1. 在任何随机调用前验证 `N,B∈N_0`、`1≤c<∞`、`p,q` 有限非负、目标支持上所需的 `q>0`、有限比率、支持覆盖以及全局 `p≤cq`。
2. 验证通过后初始化 `m=a=0` 与 `X_{1:a}=∅`。
3. 先判 `a=N`，再判 `m=B`；只有两者均否才调用提议源。
4. 提议源失败时 `m` 不增加，失败位置为下一次提议 `m+1`；成功生成一个候选后立即令 `m←m+1`。
5. 再调用均匀源；若失败，保留已经增加的 `m`，失败位置为当前 `(m, 均匀源)`。
6. 求值并核对 `p(Y),q(Y)` 有限非负、`q(Y)>0`、比率有限；失败返回 `numerical_failure`。
7. 核对 `0≤rho≤1`；越界返回 `invalid_input` 与 `envelope_condition_failure`，禁止裁剪或当作普通拒绝。
8. 只有 `U≤rho` 才原子追加 `Y` 并增加 `a`；否则是普通拒绝。两支随后共同回到“先 `a=N`、再 `m=B`”的门。

其中图内 `rho` 写为 `\rho=p(Y)/(cq(Y))`，正文公式语义未改。

## 4. 状态机不变量

- `0≤a≤m≤B`；在进入随机调用前已满足预算门，成功生成一次候选才使 `m` 恰增一。
- `|X_{1:a}|=a`；前缀只含通过 `U≤rho` 的候选。
- 普通拒绝保持 `X_{1:a}` 与 `a` 不变，但保留本轮已经增加的 `m`。
- 提议源失败保持原 `m,a`；均匀源、密度/比率、包络失败保留成功候选已经计入的 `m`，但均不增加 `a`。
- 任一失败出口返回最后合法样本前缀、实际 `m,a`、规范 `status` 和最终 `diagnosis`，并携带失败位置/阶段。
- 每轮提交或拒绝后先检查完成条件；因此 `a=N` 与 `m=B` 同时成立时 `completed` 唯一胜出。

## 5. 七个边界场景

| 场景 | 唯一路径与输出语义 |
|---|---|
| `N=0` | 完成输入预检并初始化后，首个 `a=N` 为真；返回空前缀、`m=a=0`、`completed` 和零目标诊断，不调用提议源或均匀源。`N=B=0` 也由该优先级处理。 |
| `B=0` 且 `N>0` | `a=N` 为假、`m=B` 为真；返回空前缀、`m=a=0`、`budget_stop` 和工作量诊断，不调用随机源。 |
| `N/B` 同轮同时命中 | 接受分支可能同时令 `a=N,m=B`；回路先到 `a=N`，因此返回完整 `X_{1:N}` 与 `completed`，不会落入 `budget_stop`。 |
| 普通拒绝 | 候选已经成功生成，故 `m` 已增加；不追加 `Y`、不增加 `a`，随后按完成优先、预算次之复查。 |
| 非法包络 | 预检发现支持/全局包络证书失败时，以零计数返回 `invalid_input`；运行时发现 `rho` 越界时保留已有前缀和当前 `m,a`。两者的包络诊断均为 `envelope_condition_failure`。 |
| 随机失败 | 提议源失败保留原计数并报告 `(m+1, 提议源)`；均匀源失败发生在候选成功之后，保留已增加的 `m` 并报告 `(m, 均匀源)`；状态均为 `random_source_failure`。 |
| 数值失败 | `p(Y),q(Y)` 非有限/为负、`q(Y)≤0` 或比率非有限时，返回最后合法前缀和当前 `m,a`、`numerical_failure` 及 `(m, 密度/比率)` 诊断。 |

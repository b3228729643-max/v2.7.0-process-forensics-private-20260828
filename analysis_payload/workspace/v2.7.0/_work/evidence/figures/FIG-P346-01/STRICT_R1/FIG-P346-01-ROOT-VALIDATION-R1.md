## 结论

**ROOT VALIDATION: FAIL。不得进入 SA3；下一角色为唯一 SA2。**

根级以官方 R93 的物理页 375、印刷页 362、图 20.1 为准，已完整读取 SA1 报告及 CSV，并在原生 1:1 尺度打开：`B(θ,2)：下界`—虚线下界曲线 raw ROI、独立 TEXT mask、独立 DATA_CURVE mask、overlap mask 与叠加图；公式运算符、刻度 `2`、相切说明 ROI；全图测量 overlay、彩色/灰度/独立图和整页视图。

## 硬门确认

- `B(θ,2)：下界` 与下界曲线有 50 个真实非法前景交叠像素，净空 0 px，最近坐标重合；原始 ROI 中可直接看见虚线穿过公式文字。该结果不是 bbox 外扩或膨胀 mask 误报。
- 50 个 token 中 46 个有效源字号低于 9.5 pt；5 个实际像素高度、4 个同类比例和 3 个角色比例失败。
- 正文声称存在“旧点、新点和上升箭头”，当前图中没有这些对象，图文一致性失败。
- 119 个关系中仅上述 1 个失败；其余 text-text vector bbox 最小净空 22.1158 px，裁切总数 0。数学下界/相切关系和灰度编码通过，但不能抵消任一硬失败。
- 字体视觉协调不通过：8.5 pt 刻度形成过小 BASE，9.0/9.2 pt 公式、注释和直标同时低于绝对字号门，并造成角色比例失衡。不得继续缩小文字。

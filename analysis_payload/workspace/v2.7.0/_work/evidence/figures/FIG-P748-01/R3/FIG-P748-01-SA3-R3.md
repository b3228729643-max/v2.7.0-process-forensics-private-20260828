## 唯一阻塞项：ARI 支持域错误

图源稳定性卡（第 24--27 行）与 page/standalone PDF 都明确写为 `ARI↑ [0,1]`，但 C08 只使用未重定义的 `ARI`，没有声明截断、平移或归一化变体。标准 Adjusted Rand Index 并不总在 `[0,1]`；它可为负，故图中范围会排除合法的“低于偶然一致”稳定性结果。

独立复算的可核对反例：取 4 个对象，真分组为 `{1,2}/{3,4}`，预测分组为 `{1,3}/{2,4}`。其 2×2 列联表各格均为 1，故

```
sum_ij C(n_ij,2) = 0
sum_i C(a_i,2) = 2,  sum_j C(b_j,2) = 2,  C(4,2) = 6
expected = 2*2/6 = 2/3
denominator = (2+2)/2 - 2/3 = 4/3
ARI = (0 - 2/3) / (4/3) = -1/2
```

因此，除非明确将指标改名并定义为限制在 `[0,1]` 的归一化稳定性分数，否则 `ARI [0,1]` 是实质性统计语义错误。应将标准 ARI 的可取负值边界如实说明，或明示并定义替代指标；在修正前该 blocker 使总体结论为 FAIL。

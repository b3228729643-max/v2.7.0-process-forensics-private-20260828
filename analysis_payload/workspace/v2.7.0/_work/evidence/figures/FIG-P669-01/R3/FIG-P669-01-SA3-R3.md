## 独立数学与几何复算

- 固定 `m=(0.5,0.3,0.2)`，三个浓度的 `alpha=alpha0*m` 分别为：`alpha0=3 -> (1.5,0.9,0.6)`，`10 -> (5,3,2)`，`30 -> (15,9,6)`；均为正且与图中参数一一对应。
- 左侧轴从 0 到 30 为线性：三个点的归一化位置为 `3/30=0.1`、`10/30=1/3`、`30/30=1`；与图源以 `alpha0/30` 放置标记的公式相同。
- 令 `C=diag(m)-m m^T`，并用图中投影 `A=[[0,4,2],[0,0,2 sqrt(3)]]`。独立计算得到
  `A C A^T = [[3.04,0.277128129211],[0.277128129211,1.92]]`，
  所以 `Sigma_xy(alpha0)=A C A^T/(alpha0+1)`；投影中心为 `(1.6,0.692820323028)`，正是图源中心。
- 上述分子矩阵行列式为 `5.76`。对 `alpha0=3,10,30` 复算出的下三角 Cholesky 因子依次为
  `[[0.871779788708,0],[0.079471941424,0.688247201612]]`、
  `[[0.525702992538,0],[0.047923383830,0.415028678320]]`、
  `[[0.313152544504,0],[0.028547164084,0.247225693029]]`，
  与图源的椭圆变换逐项相符。
- 以 Mahalanobis 半径 `0.8` 画椭圆，面积为 `pi*(0.8)^2*det(L)`；独立数值为 `1.206371578978`、`0.438680574174`、`0.155660848900`，比例精确为 `1 : 4/11 : 4/31`。这验证椭圆是协方差尺度，而不是密度等高线或置信域。
- 最大椭圆（`alpha0=3`）对三个概率坐标的全椭圆下界为 `(0.300000000000, 0.116696972202, 0.040000000000)`，均严格为正；后两组只会进一步收缩，因此三椭圆均完全位于单纯形支持域内。
- 图源中每条曲线箭头的终点是对应 `mu-0.8*L*(1,0)^T` 的已命名椭圆边界点，故左轴参数、箭头线型和右侧椭圆之间存在实际的、而非示意性的对应关系。

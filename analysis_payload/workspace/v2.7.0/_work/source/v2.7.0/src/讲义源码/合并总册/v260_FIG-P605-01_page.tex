\sectionmark{收敛与样本诊断}

\begin{theorem}[有限状态 MH 的正确性条件]
设状态空间有限且 $\pi(x)>0$。若 MH 核不可约且非周期，则 $\pi$ 是唯一平稳分布，并且链从任意初始分布收敛到 $\pi$。
\end{theorem}

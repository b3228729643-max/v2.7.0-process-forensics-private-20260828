\chaptermark{概率论基础}
\begin{proof}
令$\mu_X,\mu_Y$为$X,Y$在$(\mathbb R,\mathcal B(\mathbb R))$上的分布测度。对每个$b\in\mathbb R$，
\[
\mu_X(( -\infty,b])=F_X(b)=F_Y(b)=\mu_Y(( -\infty,b]).
\]
两个左半直线的交仍是左半直线；由概率测度的$\pi$--$\lambda$唯一性定理，$\mu_X$与$\mu_Y$在全部 Borel 集上一致。
\end{proof}

## 2. 两个并列合法协议

### 协议 A：开发集选择＋锁定测试

1. 开发数据 `D` 进入 `C_in` 折候选拟合。
2. 仅凭开发证据选定并冻结候选、超参数和停止规则。
3. 冻结候选后在完整 `D` 上重训。
4. 锁定测试 `T` 只开封一次并进入最终评价。

协议 A 在图、caption 和正文中对应算法 37.1。

### 协议 B（嵌套交叉验证）

1. 对每个外层折 `c`，外层训练部分为 `D_{-c}`，外层评估折为 `D_c`。
2. 每个 `c` 内都重新执行 `C_in` 折拟合和候选选择，而非复用其他外层折的选择结果。
3. 冻结该折候选后，在完整 `D_{-c}` 上重训。
4. 只用 `D_c` 产生该折外层损失，最终汇总 `C_out` 个损失。

图内 alt 与正文明确协议 B 是另一完整协议，不是算法 37.1 的“隐藏外循环”。全图协议变量统一为 `c/C_out`；没有 `D_{-k}`、`D_k` 或 `$K$` 残留。

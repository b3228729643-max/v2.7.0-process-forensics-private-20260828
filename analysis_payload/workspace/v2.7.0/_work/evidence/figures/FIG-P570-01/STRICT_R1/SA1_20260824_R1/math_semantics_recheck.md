# FIG-P570-01 数学、概率与图文语义独立复算（SA1）

图 31.1 的箭头表示教学依赖而非单次算法的执行时间。期望/积分、独立抽样和大数规律共同支撑 Monte Carlo 估计；之后的逆变换、接受--拒绝和重要性抽样是并列方法，不能被图误读为彼此等价或串行步骤。相邻正文 L76 明确给出这个限制，并区分接受--拒绝产生未加权目标样本、重要性抽样保留提议样本并改变贡献权重。

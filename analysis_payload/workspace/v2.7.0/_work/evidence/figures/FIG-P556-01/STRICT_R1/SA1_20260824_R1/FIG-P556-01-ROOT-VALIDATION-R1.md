## 根线程独立回读

- 冻结对象为官方 R93 物理第 601/813 页／印刷第 588 页／图 30.4。根线程已查看整页、原生 300 dpi 图裁、standalone、灰度、测量 overlay，以及 `REL_0251` 的原始 ROI、双方独立 mask、交集和最近邻 8× 图。
- 源级字号：124 个 glyph 中 76 个、对应 20 个语义组件低于 9.5pt；刻度为 8.7pt、曲线标签 9.3pt、轴／固定点标签 9.4pt、初值与说明框 9.2pt。普通图内文字的字号与视觉协调硬门失败。
- 逐字像素：30 个 glyph 低于各自脚本／符号门槛；同类比例严格按“同面板＋同语义角色＋同脚本类别”的 raw `H_ink` 比较，未使用 exact-glyph 分组或 PDF 字号代理。角色层级只对可比脚本相对 BASE 计算；无同脚本 BASE 的项目显式记为 N/A，不跨脚本制造失败。
- `after_overlap_report.csv` 共 735 个登记关系。唯一非法相交对为 `REL_0251`：曲线标签 `y=0.2+0.5r` 与参考虚线 `y=r` 的两个独立、未膨胀原始 mask 相交 30px，净空 0；clip 总数为 0。根线程在 1:1 原始 ROI 与 8× 最近邻图中均确认虚线穿过字形。
- 映射、固定点 `r*=0.4`、两条 cobweb 序列与概率向量均复算正确；但图内 `r^*` 与题注 `r_\star` 指向同一固定点却未声明等价，图文记号一致性失败。
- 灰度、单面板页面融合与数学／概率语义通过，不能覆盖字号、像素、比例、重叠及记号一致性硬失败。
- `machine_terminal_check.csv/json/md` 的 8 项终检均通过；A4 原生 300 dpi 网格为 2481×3508px，轴向整数像素舍入误差分别为 0.027550% 与 0.003562%，没有 resize。`MACHINE_EVIDENCE_INTEGRITY_PASS=true` 只表示失败证据完整一致，质量结论仍为 FAIL。

## SA2 边界

只可定向修复本图源及题注的同一固定点记号：所有普通可见角色提升到至少 9.5pt，重排映射标签与参考虚线使相交为 0 且净空至少 3px，并统一 `r^*`／`r_\star`。不得整体缩放、修改公共样式或中央状态。修复后必须生成新官方候选并重新执行全新 SA1、隔离 SA3 与根验收。

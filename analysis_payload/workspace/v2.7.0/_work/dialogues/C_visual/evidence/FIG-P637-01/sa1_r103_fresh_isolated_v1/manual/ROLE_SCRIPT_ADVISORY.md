# R168 peer/metadata advisory

The source declares 9.2pt for general figure text and 8.8pt for state numerals (ratio 0.9565). The official PDF exposes caption observations near 9.96–9.99pt versus figure observations near 9.165pt (approximately 1.087–1.090 depending on glyph metadata). These are micro-scale role/metadata differences and are advisory under R168. Direct native and exact-8x review found no obvious severe size imbalance or actual unreadability.

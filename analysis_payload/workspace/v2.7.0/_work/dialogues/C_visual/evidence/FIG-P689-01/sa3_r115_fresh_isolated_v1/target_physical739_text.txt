读前自检：证明：KL–ELBO 恒等式。 KL–ELBO 恒等式假定 0 < 𝑝(𝑤) < ∞、𝑞 对后验绝对
连续且相关项绝对可积；请把 log 𝑝(ℎ ∣ 𝑤) = log 𝑝(𝑤, ℎ) − log 𝑝(𝑤) 代入 KL，核对 KL(𝑞‖𝑝) =
log 𝑝(𝑤) − ℒ(𝑞)。


证明. 由 0 < 𝑝(𝑤) < ∞ 与绝对连续性，Bayes 等式在 𝑞 几乎处处成立：log 𝑝(ℎ ∣ 𝑤) = log 𝑝(𝑤, ℎ) −
log 𝑝(𝑤)。上述绝对可积条件允许分别积分并整理，不会出现 ∞ − ∞：

                              KL(𝑞‖𝑝) = 𝔼𝑞 log 𝑞(ℎ) − 𝔼𝑞 log 𝑝(ℎ ∣ 𝑤)
                                        = log 𝑝(𝑤) − ℒ(𝑞).

KL 非负给出下界与等号条件。

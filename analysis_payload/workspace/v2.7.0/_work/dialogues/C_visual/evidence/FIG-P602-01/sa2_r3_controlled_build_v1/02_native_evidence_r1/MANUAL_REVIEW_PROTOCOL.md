- Candidate PDF: `68188DAAAF9B3C4233D5A032C3D8BE20A73B51D5E6058D0E1C12FDE6471093E7`.
- Source: `6C4E8F156709C0FF384F9E7B7F2BD5D9CB586E24206BF0BCD2E58933ED3DB47D`.
- Review basis: fresh native 300 dpi render, four required views, five native-nearest 8x landmarks, 30 object cards, 154 glyph cards, 435 unordered-pair cards, and 16 critical-pair enlargements.
- A manual PASS is recorded only after the named ID was inspected for completeness, legibility, clipping, unintended collision, and its local semantic role. Machine PASS is corroboration, never a substitute for the manual judgment.
- Whitelisted zero-clearance pairs pass only when the visible contact is the intended endpoint/border/rule topology; all other contacts fail.
- Every manual ledger row contains an explicit ID-level decision and an ID-specific note. No loop, default decision, global boolean, or machine script generated or overwrote reviewer decisions or notes.
- Hard-gate failures cannot be waived by natural-glyph appearance or by relabeling an element after measurement.
- Outcome scope is C-local candidate evidence pending main acceptance; it is not central inventory, global PASS, or permission to commit.

常见错误
先保留数学主线。细致平衡只推出平稳，不推出不可约、唯一平稳或遍历；另外，MH 目标
核必须存在有限正归一化常数。两个最小反例分别是恒等核𝐾= 𝐼2 和不可积的非负目标核。

学习策略。MCMC 在统计学习中的策略不是直接最小化一个经验风险，而是把后验期望、预
测积分或隐变量期望写成式(32.1)，再同时满足四项设计目标：
1. 目标保持：𝜋𝐾= 𝜋；
2. 可达性：目标支持内的重要区域属于同一可通信部分；
3. 可计算性：只使用˜𝜋的点值、提议抽样和提议密度比；
4. 统计效率：在正确性不受损的前提下降低相关性与计算成本。
第1 项是代数条件，第2 项是图或测度结构条件，第3 项是可计算条件，第4 项才涉及调参。高
接受率、漂亮轨迹或小的经验MCSE 都不能替代前3 项。

后保存完整状态与接受标志，按式(32.2) 计算估计，并另行报告诊断。算法32.1 在后文给出数学

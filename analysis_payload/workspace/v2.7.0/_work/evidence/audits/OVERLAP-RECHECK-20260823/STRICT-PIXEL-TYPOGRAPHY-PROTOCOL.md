# 已接受绘图重新审查：原生像素与字体层级协议

本协议适用于当前续跑中所有曾被接受或曾在对话 `v2.7.0` 中判过通过的图，以及此后进入根线程终验的**全部新图与返修图**。旧报告中的 `PASS` 只用于定位候选，不能作为本轮结论；后续任何 subagent 的宽松口头判断也不能替代本协议证据。若本文件与发布根 Goal 第 9.2.1 节或 `STRICT_FIGURE_EVIDENCE_SCHEMA.md` 有差异，以两者中更严格且更新者为准。

## 1. 锁定实际候选

1. 逐 UID 锁定根线程当前冻结的官方最终全书候选 PDF、物理页、印刷页、图号、源文件和轮次；旧 `ROOT-ACCEPTANCE` 只用于定位，不得代替当前候选身份。
2. 禁止把旧 round、standalone、局部构建或另一版全书的证据与当前官方候选混用。
3. 任一要求的证据类型无法从身份明确的同一官方候选只读导出时，结论直接 `FAIL`；不得补写为 `PASS`，也不得以 `AMBIGUOUS` 继续流转到 SA3。

## 2. 三类原始证据

每个 UID 均须检查：

- 最终 `full_page_200dpi`（只看页面融合）；
- 最终彩色 `figure_crop_300dpi`；
- 最终 `standalone_300dpi`；
- 最终 `grayscale_300dpi`。

先记录每张图的 native dimensions。检查必须在原始像素上完成；浏览器缩放、整页缩略图和重采样放大只能用于导航，不能作为终审证据。

300 dpi 图必须直接从同一官方候选 PDF 原生渲染，渲染后不得 resize；只能写入该角色自己的证据目录。报告必须列出 PDF、物理页、页面 pt、原生像素网格及裁图整数坐标。身份不能锁定、原生渲染失败或视图缺失均为证据 `FAIL`。

## 3. 1:1 ROI 流程

1. 列举所有可能交互区：文字/公式对坐标轴、曲线、箭头、刻度、边框、图例、标记、阴影、另一段文字及相邻面板；公式须同时列出可能由 PDF path 绘制而不出现在 `rawdict` 字符流中的重音/规则。
2. 每个交互区制作不缩放、不插值的 1:1 ROI，报告原图坐标 `[x,y,width,height]`。
3. 对每个非 `PASS` 区域再做紧裁剪，报告最近像素或接触像素的原图坐标、对象身份、RGB/实墨判断和最小净空估计。
4. 抗锯齿像素属于可见墨迹边缘；不能把浅色抗锯齿带忽略为白隙。
5. 轴线与其组成部分（轴箭头、刻度）之间的有意连接不算冲突；文字与轴、独立箭头与无关曲线等独立对象之间的接触均算冲突。

几何判定：

- 任意两个不应相交的独立前景对象有 `>=1 native px` 非法交叠：`FAIL`；
- 文字—文字独立语义对象 PDF/vector bbox 净空 `<4px`：`FAIL`；
- 文字/公式墨迹—线、箭头或标记净空 `<3px`：`FAIL`；
- 节点文字/公式—节点最终可见边框描边净空 `<5px`：`FAIL`；
- 文字—面板裁切边/图像边净空 `<6px`，或跨面板最近读者元素净空 `<8px`：`FAIL`；
- `CLIP_PIXEL_COUNT>=1`、对象归属不能可靠分离、空 mask 或证据未知：`FAIL`；
- 修复候选应尽量达到 `>=12 native px` 的根级安全目标，但不得用安全目标替换上述分类硬门。

任一证据类型 `FAIL`，整个 UID 的几何门即为 `FAIL`。

## 4. 字号与视觉层级门

### 4.1 源级检查

- 读取当前实际图源中的全局 `every node` 字号及所有局部 `fontsize`、`tiny`、`scriptsize`、`footnotesize`、`small`、`large`、`resizebox`、`scalebox`、`scale`、`transform shape` 等覆盖，计算 `declared_pt × 累计 graphics_scale = effective_pt`。
- 一般读者文字和基准公式 `effective_pt >=9.5pt`。只允许由 `>=9.5pt` 基准公式自然派生的 TeX 上下标/上下限低于 9.5pt，且仍须通过 15px 脚本门；禁止人为把整条公式设为 scriptstyle 缩小。
- 允许为消除突兀、过密或碰撞适当缩小，但缩小后必须同时满足 9.5pt、逐字形像素、D/E 比例、分类净空、零重叠/裁切、灰度与整页协调；任一项失败即不得通过。
- 同面板同角色源级字号最大/最小 `<=1.03` 且绝对差 `<=0.25pt`；跨面板同角色最大/最小 `<=1.05`。

### 4.2 300 dpi 实墨测量

必须逐一测量全部可见字形及关键运算符/标点 substring，不能抽样或用父行高度代替。每个字形只能使用来自官方 300 dpi 原图的自身最终可见 raw mask：纯中文/全角/近全高字符 `>=30px`；拉丁大写/数字 `>=24px`；拉丁/希腊小写 `>=17px`；基准数学/运算符/分数主体 `>=22px`；合法自然脚本 `>=15px`。低笔画 CJK 不得降类。

每个可见字形必须闭合 `CHAR↔实际轮廓↔父对象↔bbox↔mask`，输出 100% contact sheets 并在 8× nearest-neighbour 下逐格人工查看。contact sheet 必须同时展示原图上下文、独特色目标 mask overlay 与 mask-only；目标 mask 与纹理、阴影、邻字、线条、箭头、标记、边框或背景的污染交集必须为 0。无法隔离、映射错误、污染、空值或未知均为证据 `FAIL`。

数学公式的可见轮廓不能只按 PDF 文本字形盘点。`\overline`/`\underline`、帽号/矢量重音路径、根号横线、分数线、消去斜线等由 drawing/path 输出的规则，须逐条作为 `GRAPHIC/MATH_RULE` 前景对象建立唯一 mask、绘制序号、语义父公式、1×/8×四联人工证据并进入总对象与全部无序 pair。它与同父公式字形的设计性组成关系可以逐对写明白名单，但它与轴线、边框、曲线、箭头、标记、其他文字或跨面板对象仍执行正常重叠/净空门。若文字 bbox 显示有净空而规则路径实际接触，必须以规则 raw mask 为准；漏规则、误并入轴/邻字、空 mask 或未对账 drawing/path 均为证据 `FAIL`。

同面板同脚本同角色，每元素高度/角色中位数须在 `[0.92,1.08]`，同角色中位数极值比 `<=1.08`；跨面板同角色中位数极值比 `<=1.10`。相对普通正文 BASE：轴标题/单位 `[1.00,1.18]`、图例/普通注释 `[0.95,1.10]`、公式块 `[1.00,1.18]`、面板标号 `[1.05,1.20]`；不可比脚本必须明确 `N/A`，禁止跨脚本或按精确字形分组规避比较。

即使数值比例未越线，只要局部字号、字重、行距或基线在整图中明显突兀、喧宾夺主、过小、过密或挤压相邻对象，`FONT_VISUAL_HARMONY_PASS=false`；不得以“数学内容正确”覆盖视觉层级失败。未知或不确定直接 `FAIL`。

## 5. 单 UID 报告模板

每个 UID 必须包含：

1. official candidate/round/physical page 与四视图路径；
2. native dimensions、页 pt、裁图整数坐标；
3. 全量源级字号覆盖清单；
4. 100% 字形映射、mask、像素、D/E 与 contact-sheet 记录；
5. 全部独立关系 pair、数学重音/规则对象 ledger、失败/临界 ROI、双方 raw mask、intersection、1:1 与 8× nearest 证据；
6. `OVERLAP_PIXEL_COUNT=0`、`CLIP_PIXEL_COUNT=0` 及各分类最小净空；
7. `FONT_VISUAL_HARMONY_PASS` 与四视图人工结论；
8. 数学语义、图文一致、灰度和页面融合；
9. CSV/JSON/Markdown/RESULT 机器交叉终检。任何一门不是 `PASS`，UID 总结论不得为 `PASS`。

## 6. 独立性与处置

- 审查代理只写其专属审查报告和获准的临时 ROI 目录，不修改源码、构建物、manifest 或中央状态。
- 此后每个 SA1/SA3 终审任务都必须先完整读取本协议和 `STRICT_FIGURE_EVIDENCE_SCHEMA.md`，并逐项给出完整几何、字体、逐字形、D/E 与四视图证据；SA2 源码代理也必须遵守 `>=9.5pt`（合法自然脚本例外）、逐字像素、层级比例和“不得突兀”要求，但无权自行宣布最终视觉通过。
- 根线程验证审查分组并集与目标清单完全一致，复核所有 `FAIL` 与证据缺口后统一撤回中央通过状态。
- 状态文件只在整批审查结果收齐后由根线程单写者更新一次；随后逐 UID 进入专属修复、重建和新的独立终审。

\begin{optimizationbox}
\textbf{优化解释。}当策略取经验风险最小化时，学习被写成
$\widehat f\in\arg\min_{f\in\mathcal F}\widehat R_T(f)$。
假设空间给出可行域，风险给出目标函数，算法近似或精确求解该问题。若目标有多个极小点，还必须声明并列处理规则，输出才可复现。
\end{optimizationbox}

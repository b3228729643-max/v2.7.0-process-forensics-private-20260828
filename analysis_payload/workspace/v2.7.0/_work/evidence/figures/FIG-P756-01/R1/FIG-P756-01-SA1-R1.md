## findings

### F-01 - lower-panel object relations overstate an exclusive method/engine partition (FAIL)

The upper panel is coherent: problem definition, modelling, computation, evidence and boundary form a five-stage forward chain, and a boundary/evidence-failure arrow returns to problem definition. The lower panel also correctly merges both branches into isolated validation and then uses one forward-only exit to reproducible reporting.

The branch-to-engine relation is not generally valid, however. `full_course_synthesis_map.tex:54-57,73-78` sends the supervised branch only through “线性代数／优化” and the unsupervised branch only through “概率／推断”. The caption repeats this pairing. In the same chapter, LSA/PCA use SVD and NMF uses optimisation despite being unsupervised; topic models use EM/variational/MCMC inference; supervised probabilistic models can also use probabilistic inference. The chapter-local source registry likewise describes unsupervised method families as reusing SVD, EM, posterior inference and power methods. Thus the geometry suggests a partition where the course content requires shared computational engines.

**Required repair:** preserve the two task routes but route both to a shared engine layer, or add explicit non-exclusive cross-links showing that linear algebra, optimisation and probabilistic inference are reusable engines. Update the caption, reading conclusion, alt text and centrally owned manifest/JSON wording together so they state sharing rather than an exclusive supervised-versus-unsupervised assignment.

### F-02 - source and key PDF text violate the font contract (FAIL)

The canonical manifest requires source-level labels `>=9.5pt` and key PDF text `>=8.876pt`. The figure-wide style and `every node` are 9.2 pt (`full_course_synthesis_map.tex:3,12`); the return explanation is 9.0 pt (line 46); station numbers are 8.0 pt (line 41); and the key “仅此单向出口” label plus route legend are 8.8 pt (lines 80,82). The 8.8-pt one-way-exit statement is below even the explicit key-PDF floor. The source comment claiming 9.8-pt priority labels does not match the implemented values.

**Required repair:** make ordinary reader-visible text at least 9.5 pt and keep semantically critical labels at or above the PDF floor after rebuilding. Reflow/widen the lower nodes so “经验风险”, “结构目标” and “变分” do not break inside words. Do not scale the assembled picture down.

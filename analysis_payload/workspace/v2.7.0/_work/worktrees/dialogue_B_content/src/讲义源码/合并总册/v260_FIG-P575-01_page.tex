\chaptermark{蒙特卡罗方法与直接采样}
\sectionmark{逆变换抽样}
对 $0<u<1$ 定义广义逆
\[
  Q(u)=\inf\{x:F(x)\ge u\}.
\]
若 $U\sim\mathrm U(0,1)$，则 $Q(U)$ 的分布函数为 $F$。图\ref{fig:V5-C02-generalized-inverse}把严格递增与离散跳跃放在同一“首次达到”规则下；即使 $F$ 有平坦段，普通代数逆可能不存在或不唯一，广义逆仍有定义。

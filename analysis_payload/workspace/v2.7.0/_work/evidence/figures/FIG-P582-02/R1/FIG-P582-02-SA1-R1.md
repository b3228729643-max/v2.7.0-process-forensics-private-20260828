   \[
   \mathrm{ESS}=\frac1{\sum_i w_i^2},

   但相邻正文式(31.15)用 \(w_i\) 表示未归一化权重、用 \(\widetilde w_i\) 表示归一化权重。虽然四个图示数值确实已经归一化，当前图仍与本章符号约定不一致；脱离题注后还会把一般未归一化权重公式误写成缺少分子的形式。

4. 数值清单存在微小但可定位的精度漂移：精确复算为
   \[
   \mathrm{ESS}=1/0.8138=1.228803145736\ldots,

## MATH_SEMANTICS

复算结果：

- 权重和：\(0.90+0.05+0.03+0.02=1\)，确为归一化权重。
- 平方和：
  \[
  0.90^2+0.05^2+0.03^2+0.02^2
  =0.81+0.0025+0.0009+0.0004
  =0.8138.
  \]
- ESS：
  \[
  \frac1{0.8138}=\frac{5000}{4069}
  =1.228803145736\ldots\approx1.23.
  \]
- 对四个非负归一化权重有 \(1\le\mathrm{ESS}\le4\)；均匀权重 \(1/4\) 给出最大值4，单一权重为1时给出最小值1。本图结果落在合法区间并接近退化端。
- “权重集中度指标，不等于可靠性证明”和题注中的可靠性边界正确；相邻正文进一步说明ESS不能发现共同遗漏的支持区域，例31.1也给出已观察权重相等但估计严重失真的反例。
- 数值本身通过，失败点是图卡没有沿用正文的 \(\widetilde w_i\) 符号。

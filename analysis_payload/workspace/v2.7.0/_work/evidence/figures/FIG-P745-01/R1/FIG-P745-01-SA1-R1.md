## findings

### F1 · PASS · 数学与协议数据流

- 协议 A 的顺序为：开发数据 `D` → `C_in` 折内拟合 → 只用开发证据选择 → 完整开发集重训 → 锁定测试 `T` 只访问一次。测试只流入最终评价，没有返回选择节点。
- 协议 B 的顺序为：对每个外层折 `c`，仅在 `D_{-c}` 中重新执行 `C_in` 折选择，锁定配置后在完整 `D_{-c}` 重训，再由 `D_c` 产生外层损失；最终汇总 `C_out` 个损失。
- 该语义与正文 `V5-C08.tex:453-460`、`563-583`、`672-680` 一致；正文还明确说明算法 37.1 只实现协议 A，协议 B 不是隐藏循环。
- 本图不含需要重新计算的连续曲线或数值表。`C_in`、`C_out`、`D_{-c}`、`D_c` 的索引与集合关系有定义，未发现数值错误或错误的训练/测试反馈边。

### F2 · PASS（图本体）/ FAIL（中央描述） · 对象—关系—结论

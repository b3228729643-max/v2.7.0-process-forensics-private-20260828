## 3. 源级原生像素预算

R3.3 的 1:1 卡片 ROI 中，上下边框主色中心约相差 167px，对应源高 `.180`，故旧纵向标度约 `927.8px/y-unit`，固定绘图区高约 `510.3px`。R2.5 在 `ymax=.61` 下的预计标度为 `510.3/.61≈836.5px/y-unit`。下表用 R3.3 实测净距作基准，仅作新构建前预算，不冒充最终像素证据。

| 对象对 | 中心分离变化 | 预计/保留净距 |
|---|---:|---:|
| 卡顶 → 标题 | `.036×927.8=33.4px` → `.049×836.5=41.0px`，增加约 7.6px | 由实测 8px 提升至保守约 **15px** |
| 标题 → 中列高分数表头 | `.054×927.8=50.1px` → `.080×836.5=66.9px`，增加约 16.8px | 由 8 邻域连通提升至保守约 **15–16px** 连续白隙 |
| 表头 → 数值行 | `.054×927.8=50.1px` → `.060×836.5=50.2px` | 物理间距基本不变，不引入新压缩 |
| 数值行 → 卡底 | `.036×927.8=33.4px` → `.040×836.5=33.5px` | 保留 R3.3 实测 **18px** |
| 卡底 → 蓝色标签 | `(.353-.278)×927.8=69.6px` → `(.362-.278)×836.5=70.3px` | 保留并略增 R3.3 实测 **19px** |

\chaptermark{多元微积分与矩阵微分}
\begin{geometrybox}
\textbf{几何解释。} 梯度垂直于等值线并指向局部上升最快方向。对$\boldsymbol u\in\mathbb R^d$，Hessian作为线性映射先给出向量$H\boldsymbol u\in\mathbb R^d$；标量$\boldsymbol u^{\mathsf T}H\boldsymbol u\in\mathbb R$才是沿$\boldsymbol u$的二阶方向导数（局部曲率）。
\end{geometrybox}
\begin{optimizationbox}
\textbf{优化解释。} 负梯度最小化一阶模型；Hessian半正定是内部局部极小点的必要二阶条件。
\end{optimizationbox}

在\cref{fig:V1-C03-gradient-contour}中，等值线切向量$\boldsymbol v_{\mathrm{tan}}$满足
$\nabla f^{\mathsf T}\boldsymbol v_{\mathrm{tan}}=0$；梯度非零时，最速上升单位方向另记为
$\boldsymbol u_{\max}=\nabla f/\lVert\nabla f\rVert_2$。两者正交，不能复用同一符号。
\begin{example}[二元二次函数]
设$f(x_1,x_2)=x_1^2+2x_1x_2+3x_2^2$。求梯度、Hessian，并判断原点的性质。
\end{example}

## 2. R3.2 阻断到 R2.4 修复映射

R3.2 的严格原生像素证据为：standalone 中卡片下边框 AA 实墨止于 `y=578`，蓝色“实线 $p(x)$”标签 AA 实墨始于 `y=579`；page/gray 对应为 `y=888/889`。因两者横向投影重合，中间连续纯白行为 `0px`。三张 ROI 同时表明：卡片横向溢出已经消失，曲线和中心方点没有进入卡片，但蓝色标签上缘恰好贴住卡底。

本轮不下移蓝色标签。原因是标签右端已经靠近同色目标曲线，下移会把已通过的相关对象间隔转成新碰撞。改为扩大两面板共享纵轴的上部留白，并将卡片整体置于更高的归一化轴域；卡片与标签的物理间隔因此增加，而标签相对曲线的语义位置不被主动压低。

| 对象 | R3.2 源坐标 | R2.4 源坐标 | 修复作用 |
|---|---:|---:|---|
| 共享纵轴上界 | `ymax=.52` | `ymax=.55` | 为卡片与数据/标签之间增加真实物理留白；两面板仍共享同一范围 |
| 卡片 | `y=.329..502` | `y=.353..533` | 卡底远离蓝标签、曲线和中心点，卡顶仍保留轴域上界余量 |
| 卡标题中心 | `.462` | `.497` | 保持独立首行与上边框净空 |
| 三列表头中心 | `.412` | `.443` | 与标题、数值行等距排布 |
| 三列数值中心 | `.362` | `.389` | 与表头、下边框均保留不小于 12px 的设计余量 |
| 蓝色 `实线 p(x)` 标签 | `(.38,.278)` | 不变 | 避免向下侵入目标曲线 |

卡片横坐标仍为 `.25..4.75`，三列横坐标仍为 `1.15/2.50/3.85`；横向已通过的 R3.2 布局不回退。

## 3. 原生像素标定与源坐标预算

以下是新构建前的设计预算，不替代根线程的三类 300dpi 实测。R3.2 的 `roi_card_all` 中，卡片上横边主色中心约为 `y=57.5`、下横边主色中心为 `y=227`，相差约 `169.5px`；对应源坐标高度 `.502-.329=.173`，故 R3.2 纵向标度约为 `979.8px/y-unit`，固定绘图区高约 `979.8×.52=509.5px`。R2.4 的 `ymax=.55` 因而给出约 `509.5/.55=926.3px/y-unit`。横向继续采用已验证候选的约 `115.2px/x-unit`。

普通文字在 R3.2 原生审计中的最大实墨高度为 36px；以下卡内预算按每行 36px 外接高计算。卡线 `.55pt` 在 300dpi 下半线宽约 1.14px，另对边缘 AA 留出保守量。

| 要求对象对 | 源坐标计算 | R2.4 设计净空 |
|---|---:|---:|
| 卡底 → 蓝色标签 | 旧中心分离 `.051×979.8≈50.0px`；新中心分离 `.075×926.3≈69.5px` | 相对 R3.2 的 0px 连续白行增加约 19.5px；计整像素与 AA 舍入后保守约 **18px** |
| 卡底 → 目标曲线峰 | `(.353-.300)×926.3≈49.1px` | 扣卡线、1.15pt 曲线半宽及 AA 后约 **43px** |
| 卡底 → 中心方点 | 同为 49.1px 中心分离 | 扣 2.8pt 点半径、.90pt 描边、卡线及 AA 后约 **32px** |
| 卡顶 → 轴域上界 | `(.55-.533)×926.3≈15.75px` | 扣卡线与 AA 后约 **13.6px** |
| 卡顶 → 标题实墨 | `(.533-.497)×926.3≈33.35px` | 扣 18px 半字高、卡线与 AA 后约 **13.2px** |
| 标题 → 表头 | `(.497-.443)×926.3≈50.0px` | 扣两行合计 36px 半字高后约 **14.0px** |
| 表头 → 数值 | `(.443-.389)×926.3≈50.0px` | 扣两行合计 36px 半字高后约 **14.0px** |
| 数值实墨 → 卡底 | `(.389-.353)×926.3≈33.35px` | 扣 18px 半字高、卡线与 AA 后约 **13.2px** |

最小预算出现在卡内上下边距，约 13.2px；所有指定对象对均高于 12 native px 返修目标。卡片白底仅覆盖 `y∈[.353,.533]`，而目标曲线最高为 `.300`，中心方点中心也为 `.300`，所以源级上不存在以白底遮盖数据的做法。

## 4. 数学与语义反回归

- 目标密度仍为 $p(x)=6x(5-x)/125$，且

- 左提议仍为 $q_L=(2/5)\mathbf 1_{[0,5/2]}$，积分为 $(2/5)(5/2)=1$；右提议仍为 $q_R=1/5$，积分为 $(1/5)5=1$。

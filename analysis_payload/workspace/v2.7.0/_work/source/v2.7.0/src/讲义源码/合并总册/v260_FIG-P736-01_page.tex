\sectionmark{聚类、降维、主题模型与采样的联系}
“没有标签”只描述观测条件，并不规定输出。聚类、降维、话题分析与图分析具有不同任务输出；MCMC等对象则是推断引擎，不能只按名称混为一谈。图\ref{fig:V5-C08-method-map}只总结本讲义中的代表性主路线和特定模型/求解方案的条件性复用；这些边都不是方法族与引擎之间的必要或充分关系，共享引擎也不意味着方法等价。

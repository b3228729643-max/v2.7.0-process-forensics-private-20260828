## 2. 撤回原因与源级诊断

严格审计的原生像素结论为：standalone 中旧卡边界为 `x=1366..1919, y=395..518`，旧第二行实墨包络为 `x=1274..2012`，左右分别负净空约 92px、93px；page/gray 中左右均负净空约 94px。左溢文字进入纵轴与 0.4 刻度走廊，字墨到纵轴仅 4--5px；右溢文字穿出框体。因此 `GEOMETRY=FAIL`，而字号、基线、字重和层级仍为 `TYPOGRAPHY=PASS`。

返修前磁盘图源虽然已把卡片压成两行，但第二行仍是一个不可断开的完整公式对象：

```tex
w(1)=0.96,\quad w(\frac52)=1.50,\quad w(4)=0.96
```

该对象的历史实墨宽约 738px，无法被约 553px 的卡片容纳，更不可能同时获得左右各 12px 的安全余量。只扩大卡片会继续侵入轴或面板边界；只缩小文字会违反 9.6pt 门。因此必须改变信息排布，而不是改变数学或字号。

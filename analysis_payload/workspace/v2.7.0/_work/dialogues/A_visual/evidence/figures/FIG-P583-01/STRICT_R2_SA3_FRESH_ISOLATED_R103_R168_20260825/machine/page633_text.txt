  例题 31.1 (稀有事件下的重要性抽样高方差). 在状态空间 {0, 1} 上，目标分布为 𝑝                                 =
 (0.99, 0.01)，提议分布为 𝑞 = (0.9999, 0.0001)，且 ℎ(0) = 0, ℎ(1) = 100。求 𝐼 = 𝐸𝑝 ℎ、普通
  重要性贡献的方差，并解释为什么四次都抽到状态 0 时估计和样本 ESS 会给出误导性的乐观
  诊断。
例题 31.1 解答


  读题翻译       把普通重要性抽样的单次贡献写成 𝑍 = ℎ(𝑋)𝑝(𝑋)/𝑞(𝑋)，精确计算它的均值与方
  差；再解释四个样本全落在常见状态时，为何估计值和经验 ESS 会同时显得过度乐观。
  已知与合法条件             𝑞(0), 𝑞(1) > 0 覆盖 𝑝 的支持；普通非自归一化估计使用 𝑍 的样本均值，样
  本 ESS 只由本次实际观察到的权重计算。
  为什么想到这个方法                  无偏性由 𝐸𝑞 𝑍 = 𝐸𝑝 ℎ 给出，而高方差由 𝐸𝑞 𝑍 2 − 𝐼 2 暴露；未抽到的稀
  有状态不会进入经验权重分散度。
  方法选择       先算 𝐼、两状态权重和贡献，再求 𝐸𝑞 𝑍 2 − 𝐼 2 ；随后条件于四次全取状态 0，计算
  估计、ESS 与该事件概率。
  推导/计算      计算。精确目标值为 𝐼 = 0.99 ⋅ 0 + 0.01 ⋅ 100 = 1。两状态的重要性权重与贡献分
  别为
              𝑝(0)    0.99                     𝑝(1)
                   =        ≈ 0.990099,             = 100,     𝑊 ℎ ∈ {0, 10000}.
              𝑞(0)   0.9999                    𝑞(1)

  故 𝐸𝑞 (𝑊ℎ) = 1，但 Var𝑞 (𝑊 ℎ) = 0.0001 × 100002 − 12 = 9999。若四次都抽到常见状态 0，普
  通估计为 0，相对真值误差为 −1；四个已观察权重却完全相等，经验 ESS 会给出 4。
  独立核验       二阶矩为 𝐸𝑞 [(𝑊 ℎ)2 ] = 104 ，减去均值平方再次得到方差 9999；而四次均未命中
  状态 1 的概率是 0.99994 ≈ 0.99960006，说明这种“ESS 满额但估计为零”的样本并不罕见。
  结论     𝐼 = 1 且单次重要性贡献方差为 9999；四次全取状态 0 时估计为 0、经验 ESS 却为 4。
  样本 ESS 不能发现尚未命中的稀有高贡献区域；后文例 31.2 另行审计普通均匀样本均值。

    以下四个算法都区分数学上概率为零的事件与实际出现的数值异常。有限值、定义域和支持
覆盖必须逐项检查；任何非法概率、负权重或非有限数都不能通过裁剪掩盖。

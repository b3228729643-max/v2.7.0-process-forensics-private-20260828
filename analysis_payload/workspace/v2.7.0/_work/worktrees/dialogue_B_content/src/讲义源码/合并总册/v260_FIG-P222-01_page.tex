\chaptermark{朴素贝叶斯法}
\begin{definition}[朴素贝叶斯条件独立模型]
若对每个类别$c_k$和输入$x=(x^{(1)},\ldots,x^{(n)})$有
\[
P(X=x\mid Y=c_k)=\prod_{j=1}^{n}P(X^{(j)}=x^{(j)}\mid Y=c_k),
\]
则称特征在给定类别后条件独立。
\end{definition}
\textbf{模型。}条件独立模型把完整类条件组合表降为随特征数近似线性增长的一维条件表。

\textbf{学习策略。}即使条件独立不完全成立，只要各类别得分的相对次序仍正确，分类器仍可能有效。

## findings

### F-01 — ordinary figure text violates the 9.5-pt minimum (FAIL)

`method_selection_decision_map.tex:3` sets the figure-wide style to `\fontsize{9.2pt}{11.0pt}` and line 7 applies the same 9.2-pt value to every node.  Only the two `root` nodes override this with 9.5 pt (line 8).  Thus the diamond, four family cards, validation gate, feedback label and non-return label are below the required ordinary-text minimum.  This also contradicts the canonical manifest row’s stated source minimum of `>=9.5pt`.

The current 250-DPI rendering is sharp and legible, but visual legibility does not satisfy the stated size floor.  There is no key mathematical formula in this diagram; the approximately 12-pt formula criterion is therefore not applicable, not a justification for the 9.2-pt labels.

**Required repair:** change the base and `every node` font in `method_selection_decision_map.tex:3,7` to at least `\fontsize{9.5pt}{11.4pt}\selectfont`; retain or enlarge root text as needed.  If increased text changes wrapping, widen the relevant node/canvas modestly and then perform a focused page-787 render check for non-overlap.  Do not solve this by shrinking or splitting the figure.

### F-02 — declared TikZ alt text is not actually delivered in the PDF (FAIL)

The chapter JSON declares one TikZ root and a complete object—relation—conclusion alt text for this map.  The TikZ source also supplies `alt={...}` at line 16.  However, line 4 conditionally defines an otherwise unavailable `/tikz/alt` key as a no-op.  More importantly, the current authoritative PDF catalog has neither `/StructTreeRoot` nor `/MarkInfo`; physical page 787 has no PDF structure tagging that could expose the declared description to assistive technology.  Therefore the source/JSON declaration is not equivalent to delivered PDF alt text.

**Required repair:** use the project’s actual tagged-PDF accessibility mechanism around this TikZ object (not merely a fallback TikZ key), emit an accessible figure description equal in substance to the JSON text, and verify the rebuilt PDF has a structure tree with an `/Alt` (or documented equivalent) bound to this figure on physical page 787/current regenerated page.

### F-03 — the required dedicated “先看—再看—最终” reading sentence is absent (FAIL)

The first active prose reference is `V5-C08.tex:540`, before the input at line 542: “图 37.7 给出完整决策路径。”  The preceding lines 537-540 correctly introduce the task-to-method mapping, and the caption states the three stages. The figure’s own left-to-right semantics do not substitute for that instructional sentence.

**Required repair:** immediately after `V5-C08.tex:540` and before the `\input` at line 542, add a figure-specific reading sentence equivalent to: “先看菱形以确定输出语义和必要约束；再看四个方法族及其进入验证阶段的箭头；最终沿实线得到锁定选择，并把虚线只理解为从验证阶段回修候选族、绝不从最终测试或报告回流。”  Keep the existing first citation and caption.

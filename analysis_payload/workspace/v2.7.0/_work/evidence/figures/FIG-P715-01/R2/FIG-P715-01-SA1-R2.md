## 数学复算（按结点顺序 `(i,j,h)`）

四条单位权边独立映射为：

```text
i → j  => A_{j,i}=1
j → i  => A_{i,j}=1
j → h  => A_{h,j}=1
h → i  => A_{i,h}=1
```

因而

```text
A = [ [0, 1, 1],
      [1, 0, 0],
      [0, 1, 0] ]

c = column-sum(A) = (1, 2, 1)

M = [ [0, 1/2, 1],
      [1,   0, 0],
      [0, 1/2, 0] ]

P = M^T = [ [0,   1,   0],
             [1/2, 0, 1/2],
             [1,   0,   0] ]
```

- `M_:j=A_:j/c_j`；三列和依次为 `(1,1,1)`，故 `1^T M=1^T`。
- `P=M^T`；三行和依次为 `(1,1,1)`，故 `P1=1`。
- `P_{ji}=M_{ij}=Pr(X_{t+1}=i | X_t=j)`，与图中行随机解释一致。
- 令 `rho_t=(p^(t))^T`，则 `(M p^(t))^T=(p^(t))^T M^T=rho_t P`；故 `p^(t+1)=M p^(t)` 与 `rho_(t+1)=rho_t P` 精确互为转置。
- 边支持、`A→M`、列和、行和和转置的最大残差均为 0（手工精确有理数复算）；`c_i,c_j,c_h` 均正，悬挂结点数为 0。

两个 manifest 的 source path、结点顺序、边、`c/A/M/P` 与上述独立结果一致；其 `status`/“通过”字段没有参与本结论。

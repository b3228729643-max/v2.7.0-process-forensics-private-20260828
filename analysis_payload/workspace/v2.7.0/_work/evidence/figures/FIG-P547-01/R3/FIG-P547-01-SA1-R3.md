## 2. 独立数学复算

当前图与数值清单给出的矩阵为

\[
A=\begin{bmatrix}0.7&0.3\\0.2&0.8\end{bmatrix},
\qquad
P=A^{\mathsf T}=\begin{bmatrix}0.7&0.2\\0.3&0.8\end{bmatrix}.
\]

独立复算结果：

| 核查项 | 独立计算 | 结论 |
|---|---|---|
| A 行随机 | 第 1 行：`0.7+0.3=1`；第 2 行：`0.2+0.8=1` | PASS |
| P 列随机 | 第 1 列：`0.7+0.3=1`；第 2 列：`0.2+0.8=1` | PASS |
| 物理边 `1 -> 2` | `a_12=0.3=P_21` | PASS |
| 物理边 `2 -> 1` | `a_21=0.2=P_12` | PASS |
| 自环 | `a_11=P_11=0.7`，`a_22=P_22=0.8` | PASS |
| 状态推进桥 | 对任意 `rho_t=(x,y)`，`rho_t A=(0.7x+0.2y, 0.3x+0.8y)`；令 `p^(t)=rho_t^T`，则 `P p^(t)` 得到完全相同的列向量 | PASS |
| 单点分布交叉检查 | 从状态 1 出发，两种写法均得 `(0.7,0.3)`；从状态 2 出发，两种写法均得 `(0.2,0.8)` | PASS |

因此转置只改变同一概率在矩阵中的行列位置，不改变物理边方向、概率值或一步状态推进。图中左侧 `a_12=0.3`、`a_21=0.2`，右侧 `P_21=0.3`、`P_12=0.2`，中央 `P=A^T` 与 `a_ij=P_ji` 均正确。

## Generative semantics and factor audit

The current C06 full-Bayes joint is

\[
p(\boldsymbol w,\boldsymbol z,\boldsymbol\theta,\boldsymbol\varphi
\mid\boldsymbol\alpha,\boldsymbol\beta)
=\prod_{k=1}^{K}p(\boldsymbol\varphi_k\mid\boldsymbol\beta)
\prod_{m=1}^{M}\left[
p(\boldsymbol\theta_m\mid\boldsymbol\alpha)
\prod_{n=1}^{N_m}
p(z_{mn}\mid\boldsymbol\theta_m)
p(w_{mn}\mid z_{mn},\boldsymbol\varphi)
\right].
\]

The source contains five actual directed draw commands, and they cover these
four factor classes exactly:

- \(\boldsymbol\beta\to\boldsymbol\varphi_k\) represents
  \(p(\boldsymbol\varphi_k\mid\boldsymbol\beta)\).
- \(\boldsymbol\alpha\to\boldsymbol\theta_m\) represents
  \(p(\boldsymbol\theta_m\mid\boldsymbol\alpha)\).
- \(\boldsymbol\theta_m\to z_{mn}\) represents
  \(p(z_{mn}\mid\boldsymbol\theta_m)\).
- The two ancestral inputs \(z_{mn}\to w_{mn}\) and
  \(\boldsymbol\varphi_k\to w_{mn}\), explicitly labelled “按
  \(z_{mn}\) 取一行”, jointly represent
  \(p(w_{mn}\mid z_{mn},\boldsymbol\varphi)\).

The roles and domains agree across source, definition and symbol table:

- \(\boldsymbol\beta\in\mathbb R_{>0}^{V}\) and
  \(\boldsymbol\alpha\in\mathbb R_{>0}^{K}\) are fixed Dirichlet
  hyperparameters.
- \(\boldsymbol\varphi_k\sim\operatorname{Dir}(\boldsymbol\beta)\) is a
  random topic--word probability vector in \(\Delta^{V-1}\), and
  \(\boldsymbol\theta_m\sim\operatorname{Dir}(\boldsymbol\alpha)\) is a
  random document--topic probability vector in \(\Delta^{K-1}\).
- \(z_{mn}\in\{1,\ldots,K\}\) is a latent discrete variable; 
  \(w_{mn}\in\{1,\ldots,V\}\) is an observed variable.
- The physical swimlanes visibly state
  \(k=1,\ldots,K\), \(m=1,\ldots,M\), and
  \(n=1,\ldots,N_m\) within each \(m\). This agrees with the joint
  product nesting.
- The side note correctly keeps the point-parameter variant distinct:
  each \(\boldsymbol\varphi_k\) is an estimated parameter, has no
  \(\boldsymbol\beta\) prior, and is not the same posterior as the
  complete-Bayes model.

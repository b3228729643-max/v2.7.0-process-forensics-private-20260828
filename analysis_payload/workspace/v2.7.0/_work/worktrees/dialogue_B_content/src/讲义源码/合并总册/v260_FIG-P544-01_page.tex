\sectionmark{本章依赖路线}
\paragraph{依赖路线。}初始分布与转移规则 $\to$ 分布推进 $\to$ 平稳固定点；通信关系、返回时长与平均回返时间 $\to$ 不可约、非周期与正常返；这些结构条件 $\to$ 唯一平稳分布、逐步收敛与时间平均；细致平衡 $\to$ 可逆性 $\to$ 平稳性。
